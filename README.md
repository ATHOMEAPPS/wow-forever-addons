# WoW Forever addons

Made for the Family, by Claude and EonJoe.

Two addons for the World of Warcraft **_forever_** client (interface 16001).

| Addon | Version | What it does |
|---|---|---|
| [GoldLedger](GoldLedger/) | 1.3 | Gold ledger: where every coin came from and went, by period and character, with search. Includes an on-screen "coin earned" counter, and the Ledger window can be resized from its corner. `/gl` |
| [TidyBags](TidyBags/) | 2.5 | One bag window and a bank window (Character / Warband), with search, sort, saved bags and banks for every character, and item counts in tooltips. Profession bag slots get a light colour and the bag's icon. Both windows can be resized from the corner. `/tb` |

## Install

1. Download the addon's zip (`GoldLedger/GoldLedger.zip` or `TidyBags/TidyBags.zip`).
2. Close WoW and unzip it into `World of Warcraft\_forever_\Interface\AddOns\`.
3. Turn the addon on under "AddOns" at character select.

Each folder's `INSTALL.txt` has the full steps.

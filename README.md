# WoW Forever addons

Two addons for the World of Warcraft **_forever_** client (interface 16001).

| Addon | What it does |
|---|---|
| [GoldLedger](GoldLedger/) | Gold ledger: where every coin came from and went, by period and character, plus an on-screen "coin earned" counter. `/gl` |
| [TidyBags](TidyBags/) | One bag window and a bank window (Character / Warband), with search, sort, saved bags and banks for every character, and item counts in tooltips. `/tb` |

## Install

1. Download the addon's zip (`GoldLedger/GoldLedger.zip` or `TidyBags/TidyBags.zip`).
2. Close WoW and unzip it into `World of Warcraft\_forever_\Interface\AddOns\`.
3. Turn the addon on under "AddOns" at character select.

Each folder's `INSTALL.txt` has the full steps.
